# SonyPodsWin

索尼 WH-1000XM6 头戴耳机的 Windows 控制工具：绿色单 exe，免安装，双击即用。

## 功能

- 电量显示（数字 + 环形进度），连接弹窗提醒
- 降噪 / 环境声 / 关闭 三段切换，环境声等级 1–20
- 关注语音、自适应环境声灵敏度
- 10 段均衡器与多组预设（重低音 / 清澈 / 硬朗 / 柔和 / 游戏 / 自定义）
- 托盘常驻、右键快捷切换，断线自动重连
- DSEE、连接质量、多点连接等状态查看

## 下载

到仓库的 [Actions 页面](https://github.com/ihpwhath/SonyPodsWin/actions) 打开最新一次成功构建，下载产物 SonyPodsWin-win-x64，解压运行里面的 SonyPodsWin.exe 即可（Windows 10/11，需要蓝牙）。
